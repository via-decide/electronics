# Measure

Set the DMM to DC voltage above 3.3 V. Connect black to project GND first. Probe only named test points
with the red lead and avoid adjacent pins.

**Quantity:** LED voltage, resistor voltage and calculated current I=V_R/R for each resistor.

Record instrument model, range, resolution, uncertainty if known, exact test point, state and timestamp.
Expected values belong in the expected column; actual readings belong only in measured.

Current mode is optional. Before using it, move the lead to the fused current jack, choose the highest safe range and insert the meter in series. Never place a current-mode meter across 3.3 V and GND.

Evidence filename: `02-led-current-measurements-YYYYMMDD.csv`.
