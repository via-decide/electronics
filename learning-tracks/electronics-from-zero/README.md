# Electronics From Zero

Begin at `START-HERE.md`. Complete lessons in order unless an entry path explicitly permits a review.

0. [How to Use This Repository](00-how-to-use-this-repository.md) — turn a question into a measured physical result.
1. [Electricity You Can Measure](01-electricity-you-can-measure.md) — make voltage, resistance and continuity observable.
2. [Breadboard Without Confusion](02-breadboard-without-confusion.md) — discover hidden connections and split rails.
3. [LED and Resistor](03-led-and-resistor.md) — bound current through a nonlinear component.
4. [Button and Pull Resistor](04-button-and-pull-resistor.md) — give an otherwise floating input a defined state.
5. [Transistor as a Switch](05-transistor-as-a-switch.md) — control load current without sourcing it from a GPIO.
6. [Voltage Divider and ADC](06-voltage-divider-and-adc.md) — turn a bounded analog voltage into evidence.
7. [Capacitor and Time](07-capacitor-and-time.md) — observe stored charge and RC settling.
8. [Power Supply and Decoupling](08-power-supply-and-decoupling.md) — keep local IC supply voltage defined during switching.
9. [UART](09-uart.md) — frame asynchronous bytes into validated messages.
10. [I2C](10-i2c.md) — address a register device on open-drain shared lines.
11. [SPI](11-spi.md) — control when synchronous bits move and which device answers.
12. [External EEPROM](12-external-eeprom.md) — respect page and busy-state rules during nonvolatile writes.
13. [SPI NOR Flash](13-spi-nor-flash.md) — work with program pages and erase sectors.
14. [CRC and Corruption](14-crc-and-corruption.md) — detect changed bytes before accepting an object.
15. [Power-Loss-Safe Write](15-power-loss-safe-write.md) — preserve last-known-good state across interruption.
16. [Logic Analyzer](16-logic-analyzer.md) — turn protocol timing into reviewable evidence.
17. [Oscilloscope](17-oscilloscope.md) — observe analog shape instead of inferred digital state.
18. [Custom PCB](18-custom-pcb.md) — move a proven circuit from jumpers to controlled geometry.
19. [Raw NAND](19-raw-nand.md) — manage bad blocks, spare area and ECC instead of treating NAND as NOR.
20. [Storage Controller](20-storage-controller.md) — coordinate mapping, integrity, recovery and media state.

Advanced destinations: [`projects/ssd_lab`](../../projects/ssd_lab/README.md), [`firmware/storage`](../../firmware/storage/) and [`hardware/platforms/w25n01jw_lab`](../../hardware/platforms/w25n01jw_lab/README.md).
